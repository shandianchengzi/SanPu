# 散谱 · SanPu

**旋律自由，不为凑拍子改谱。** 一个免费、开源、纯浏览器运行的散板数字简谱编辑器。无需注册、无需服务器、无需付费。

🌐 **在线体验：** https://shandianchengzi.github.io/SanPu/

## 功能

- **散板 / 自由节奏：** 允许不等长小节，不校验总拍数，不自动改动音符时值；谱面不显示源文件中的拍号。
- **跨行小节线手动对齐：** 在 `.Voice` 中使用 ABC 风格的 `y` 或 `y40`、`y80` 插入不可见横向空位。只改变 SVG/PDF 的横向排版，不产生休止、时值或歌词占位；源码编辑器提供「＋ 排版空位」快捷按钮。
- **延音连续模式：** 钢琴区可勾选「延音连续模式」（新用户默认勾选，仅在录入时生效）。第一键按下即生成带一条延长线（`-`、默认两拍）的临时音符；松开鼠标后继续显示该临时长度，下一个琴键按下时会把上一音符的时值改为两次按下之间的间隔（包含松键后移动鼠标的时间），量化仍采用当前 BPM。若松键后超过 `max(1.8 秒, 4 拍)` 没有下一键，则认为已结束连续乐句，末音保留按住时长；此后新按键开启新的乐句。编辑原始源码、切换模式或调速会终止待续录入而不修改已有音符；原有歌词、空位记号不受影响。
- **钢琴按调号移调：** 新增独立复选框「按谱面调号移调」，新用户默认勾选。勾选后以 C 调键盘为基准整体移调；例如 `1=D` 时按虚拟 C4 键会试听 D4，并录入简谱 `1`（升高两个半音，即一个全音）。关闭则保持固定绝对音高，C4 在 D 调写为 `b7,`。音符悬停提示和 C 键标记同步显示移调结果，选择保存在本地。
- **默认钢琴设置：** 新用户默认勾选「仅试听」「按谱面调号移调」「延音连续模式」三个选项，默认音色为「钢琴（合成）」；已有本地保存的选项保持原值。
- **源谱编辑器软换行：** 长音符行在左侧输入框内自动折行，不增加实际换行字符，不改变音符、歌词、空位记号、播放或导出源码。
- **延长线与音符间距：** 「间距与页面」新增独立调整项（-25～70 px，默认 0），只改变 `-` 与音符的距离，延长线之间的间距仍由原有设置控制。正值还为带延长线的音符预留水平空间，预览、PDF 和样式 JSON 同步生效。
- **批量编辑音程：** 在源码输入框与「快速记谱说明」之间有可折叠的「批量编辑」区，可输入正负整数半音数，默认 0；点击「确认移调」并二次确认后对整首曲谱移调。只修改音符的音高，保留时值、歌词、调号、小节线、圆滑线、排版空位及其他源码；遇到超出音域的音符时整次操作取消，不产生半成品。
- **电脑键盘弹奏：** 新增默认关闭的「键盘模式」。打开后按照 `C3: q2w3er5t6y7u`、`C4: zsxdcvgbhnjm`、`C5: ,l.;/i9o0p-[` 依序映射 C3～B5 全部 36 个半音键，触发与鼠标弹奏相同的试听/录入/连续节奏逻辑，并在屏幕钢琴显示按下效果；键盘模式开启时禁用源谱输入框（关闭后恢复编辑），但录入模式仍可自动添加音符；编辑其他输入框和使用操作修饰键时不触发。「快速记谱说明」中的 SVG 键位图采用真实四排 QWERTY 键盘位置（数字行、QWERTY、ASDF、ZXCV 行，包含原本未映射的灰色键及实体错位），而非将音符按音高顺序横排；会随谱面调号及移调状态动态更新音高和简谱记号，按下键盘或点击钢琴时同步高亮对应键。
- **钢琴速记：** 编辑区提供三组八度 C3–B5 的白键/黑键，根据当前调号自动换算音级、变音和高低音。钢琴键始终在按下时发声：勾选「仅试听」只弹奏不录入；取消勾选则边听边录，在普通录入模式下按住琴键并松开，将按住时长按当前 BPM 量化为 1/8–8 拍的减时线、附点或延长线，插到正在播放或已选中音符后方，并同步源谱和预览。连续琴键向后逐音录入；无选中音符时以编辑区光标为准，否则放在 `.Voice` 末尾。
- **谱面点选定位：** 点击谱面音符后自动聚焦源码输入框，并将光标放在该音符记号之后。仅试听模式下依旧从该音符开始播放；取消仅试听后点击则立即停止当前播放并选中音符，方便插入。
- **升降号与延时点间距：** 「音符与歌词」标签页新增“升降号与音符间距微调”和“延时点（附点）与音符间距微调”两个独立参数，均支持 -25 至 +70 px（默认 0，保持旧版原位）。正值分别将升降号向左、附点向右移开，同时只为含对应符号的音符预留额外水平空间；负值拉近距离，可能发生重叠。预览、PDF、样式导入导出和本地保存同步生效，不影响节奏、歌词或源码。
- **记谱人、词曲作者及演唱者：** 标题下方同一行，左侧依次为调号、试听速度及 `记谱人：shandianchengzi`，右侧右对齐展示词曲作者和演唱者。记谱人、词曲作者与演唱者分别来自 .Title 段的 `Transcriber =`（可省略，默认 `shandianchengzi`；显式空值则不显示）、`WordsByAndMusicBy =` 和 `Singer =`；后两项为空时不显示。记谱人与右侧署名可以分别调整字号和字体，PDF 输出也会保持布局。
- **MP3 导出：** 预览工具栏提供「↓ 导出 MP3」，根据完整谱面的音符时值、当前 BPM 和选中的合成音色离线渲染音频，包含 0 休止符、圆滑线的轻微音符衔接，不受播放位置影响。使用随应用发布的 @breezystack/lamejs 1.2.7 编码为 128 kbps、44.1 kHz 单声道 MP3；仅在本机运行，不上传谱面和音频。为防止浏览器内存溢出，单次最长 15 分钟。编码库 LGPL-3.0，随构建独立部署为 vendor/lamejs.js，并附原始 LICENSE；详见项目第三方许可说明。
- **试听循环：** 播放速度、音色同一栏新增「循环次数」输入框，默认 `0` 仅播放一次，正整数表示全曲额外重复次数，`-1` 无限循环；暂停后继续保留循环进度，停止立即取消；设置保存在浏览器本地，不更改音符或 MP3 导出时长。
- **BPM 数字直接输入：** 点击播放栏中的速度数值即可手动输入 35–180 BPM；输入框、滑块和谱面速度标记自动同步，超界数值会限制到范围内。滑块仍可照常使用。
- **数字简谱实时预览：** 支持 0–7、升降音、高低八度点、下划线减时、延长线、附点；调号旁标注当前试听速度（♩ = BPM）。不绘制歌词延音的弧形连接线。
- **歌词逐音对位：** `.Words` 中的 `/` 表示一个音符延续前面的歌词；空格和标点不占音符位置。标点独立绘制在文字侧边，不再导致对应音符下的歌词左移；可单独调整标点间距。
- **试听及自选音色：** 使用浏览器 Web Audio API 离线合成音符。右侧工具栏提供 7 种音色：纯音（原音色）、钢琴（合成）、吉他（合成）、长笛（合成）、弦乐（合成）、管风琴（合成）、电子方波。支持调速、暂停、停止，点击任一音符从该处播放；播放中切换音色会从当前位置接续，不会重置进度。
- **导出 PDF：** 使用浏览器系统打印功能选择「另存为 PDF」，SVG 矢量简谱，无水印。
- **导入 / 导出 JPW-ABC：** 支持 `.jpwabc`、`.txt`；兼容 UTF-8 和 UTF-16 字符编码；保存时保留编辑区中的原始音符、时值和歌词。
- **浏览器本地自动保存：** 不上传服务器，关闭网页可继续编辑（仅限同一设备浏览器）；另有「保存源码」手动备份。
- **完整排版面板：** 主工作区下方提供可收起的「谱面样式」面板，使用三个标签页整理 42 项设置。调号（`1 = C`）、速度标记（`♩ = 80`）及记谱人、词曲作者和演唱者支持独立字号设置，其他项目涵盖标题、音符、歌词、线条、字体和 PDF 页面。
- **即时预览与排版预设：** 提供标准、紧凑、宽松三套预设，可逐项拖动滑块或输入精确数值，一键恢复默认。试听 BPM 直接在右侧预览工具栏调整。
- **自适应 SVG 预览：** 默认将完整谱行等比缩放至右侧预览栏宽度，窗口变化时自动适应；右侧预览工具栏可在 50%–300% 之间调整预览缩放，放大后支持横向滚动，一键恢复「适应宽度」。缩放仅影响屏幕预览，不改变 PDF 排版。
- **样式导出／导入：** 「谱面样式」面板支持将全部排版参数保存成独立的 `.sanpu-style.json` 文件，并可在其他浏览器或设备导入复用；只包含谱面样式，不包含谱子内容、播放速度、音色及屏幕缩放。
- **本地持久化：** 自定义外观、试听速度、音色和预览缩放一起保存在本机浏览器的 `localStorage`，重新打开网页自动恢复，不会修改原始 JPW-ABC 文本。
- **响应式布局：** 上方左侧只放源谱编辑、右侧放乐谱预览与播放/缩放工具；下方整行宽度的「谱面样式」默认折叠，展开后通过三个标签页选择不同选项。窄屏自动上下排布。

## 快速上手

打开网站，默认会载入一份《一生所爱》的个人听写示例（1=D，六行旋律示例，含九处圆滑线，保留用于谱面布局的 `y`、`y10`、`y15`、`y25`、`y30`、`y35` 空位）。编辑区新增「示例曲库」选择框，选定曲目后点击「加载选中示例」；覆盖现有谱稿前会弹出确认，便于以后继续扩充曲目。左侧编辑 JPW-ABC 源文，右侧立即预览、试听。歌词与旋律的匹配遵循歌词跳音规则，而不是根据小节拍数分配。

| 记法 | 含义 |
|---|---|
| `1`–`7`、`0` | 简谱音符和休止符 |
| `3_`、`3__` | 八分音符、十六分音符 |
| `3-`、`3--` | 两拍、三拍 |
| `3.`、`3_.` | 附点四分音符、附点八分音符 |
| `7,`、`1'` | 低音、高音 |
| `|` | 小节线，可自由分句（散板模式不校验小节长度） |
| `$(true)` | 分行 |
| `y`、`y40`、`y80` | 排版留白，默认 20，或指定 40、80 SVG 逻辑单位；不占用拍数 |
| `.Words` 中的 `/` | 一字多音：当前音符不另起新歌词 |
| `.Words` 中的 `{多字}` | 一组文字对应一个音符 |
| `W1@1,1:` | 第一段歌词从第一小节第一个音符开始 |

### 用排版空位对齐不等拍小节

在普通 ABC 记谱中，`y` 是排版间隔而非休止符；SanPu 将这一写法作为 **JPW-ABC 的 SanPu 扩展**，目前**不保证原版 JP-Word 能识别**。SanPu 使用 SVG 逻辑单位衡量留白（不是音乐时长；与普通 ABC 实现中的印刷点数也不作等价保证）。

例如两行小节中的音符数不同时，为了让第一根小节线仍在同一水平位置，可这样写：

```text
.Voice
1 2     | 3 4 $(true)
1 y65   | 3 4
```

两行的第一根小节线都会绘制在默认排版中相同的横坐标上：第二行少了一个音符的宽度，就用 `y65` 补齐（**65** 只是标准布局下一个音符的约定宽度；修改音符字号、疏密后可手动改为其他数值）。`y` 表示 20 单位，`y40` 表示 40 单位，`yy` 表示两个连续的 20 单位空位；`y0` 可用于零宽占位。单个空位最大为 2000 单位，超过时 SanPu 会给出提示并限制宽度。

可以直接输入记号，也可以把光标放在 `.Voice` 需要留白的位置，点击源码编辑区的「＋ 排版空位」，快速插入 `y40`。**普通 ASCII 空格、Tab 和换行仍仅用于分隔源码记号，不会被当作谱面宽度**；因此额外输入空格不会意外改变现有谱子的排版。需要多段谱行时，继续使用 `$(true)` 显式换行。

`y` 不会在谱面上显示任何音符、休止符或占位符，不计拍数，不影响歌词按音符逐一对位，试听也不会增加静音时间。导出 PDF 会保持相同的水平排版逻辑。

### 试听音色

右侧乐谱预览工具栏的「音色」下拉框可以直接切换播放音色，适合用不同的音质试听同一首简谱。音色使用 Web Audio 振荡器与谐波包络合成，不依赖外部音频文件、SoundFont 或在线服务；钢琴、吉他、长笛、弦乐、管风琴是**合成模拟音色**，不等同于真实乐器录音。新用户默认使用「钢琴（合成）」，已有本地音色选择不会被覆盖。音色仅影响试听，不改变谱面、记谱时值及 PDF 导出结果。

### 谱面样式备份与复用

展开底部「谱面样式」面板，点击「↓ 导出样式」，浏览器会下载 `SanPu-谱面样式.sanpu-style.json`。文件为可读的 JSON，包含格式类型 `sanpu-score-style`、版本号 `1` 和 `settings` 对象；其中保存全部 42 个排版参数（包括字号、字体、音符间距、高低音点位置、歌词标点距离和 PDF 页边距），不包含乐谱源文或其他播放设置。

需要恢复或复用时点击「↥ 导入样式」，选择之前保存的 JSON。有效配置会立即应用到当前预览、PDF 和浏览器本地保存；当前乐谱源码、BPM、音色及 SVG 缩放保持不变。导入时会识别文件格式与版本、校验参数及范围，超界值会自动限制到允许范围；无效文件及超过 1 MB 的文件会显示错误，不会覆盖现有样式。旧版本样式缺少的字段使用默认值，新版本增加的未知字段忽略。

### 排版调节

在「音符与歌词」标签页，支持分别调整**高音点与音符距离**、**低音点与音符距离**（各 -50～80 px，默认 0）。正值将音点移离音符，负值使音点靠近；调整会实时更新 SVG，较大偏移会自动增加谱行内部空间，避免高低音点被裁切。现有本地设置及预设保持原来的默认音点位置。

同一标签页新增**标点与歌词距离**（-30～80 px，默认 0）。歌词正文仍居中位于所属音符下，常见句读标点另外显示在文字右侧；成对的引号分别显示在文字两侧。这个设置只移动标点，不挪动歌词正文的水平锚点。渲染时优先读取浏览器实际字宽，避免字号或字体变化导致的居中偏移。原始歌词文本、对位和试听内容均保持不变。

在「间距与页面」标签页中，可以使用「相邻两行歌词间距微调」独立压缩或拉开谱面各行之间的距离，范围 **-160～160 px**，默认 **0 px**。此参数会在现有「谱行之间的间距」上叠加偏移：例如谱行间距为 17 px、歌词间距微调为 -40 px，两行间的实际附加空隙为 -23 px（相邻行将更靠近，极端值可能重叠）。注意 SVG 本身仍包含音符和歌词的高度，此数值不是两行歌词的绝对基线距离。

间距类参数现支持通过滑块或右侧数值框输入负数，包括曲名字符间距、曲名下方间距、调号与速度间距、调号下方间距、歌词字符间距、歌词相对音符的纵向位置、音符横向疏密以及谱行间距等；每个参数均有独立的负值下限。**字号、线条粗细、PDF 页边距等绝对尺寸不会允许负数**。设置即时预览并保存至浏览器本地，打印 PDF 时也按同一间距设置排版。极端负数可能造成叠字，请结合预览调整。

内置的「标准」排版预设和首次打开的默认值，采用 `examples/standard.sanpu-style.json` 中记录的样式参数；「紧凑」「宽松」基于标准样式按比例调整标题、调号、记谱人、词曲署名、音符、升降号、歌词和线条的大小，并调整相应排版间距；字体与符号间距微调保持一致。已有本机保存的个人设置不会被升级覆盖，可点击「恢复默认」应用新的标准值。

主工作区下方的「谱面样式」默认折叠，展开后可在「标题与调号」「音符与歌词」「间距与页面」三个标签页之间切换，支持方向键切换页签。每个数值都可以使用滑块粗调，或在右侧数值输入框中精确调整；修改立即更新右侧 SVG。字体使用浏览器与操作系统现有字体，不加载网络字体。大字号会自动扩展系统高度，避免音符附点、低音点、歌词相互遮挡。

「谱行最小宽度」控制 SVG 的逻辑宽度（viewBox），预览默认将整个谱行等比缩放至右侧容器宽度，不再需要默认横向滚动。可以使用右侧工具栏中的预览缩放滑块手动放大并横向滚动查看细节；导出 PDF 时始终适应纸张宽度，不采用屏幕缩放比例。PDF 版式保持设置的相对字号和间距；特别长的一行在缩放到 A4 纸宽时实际字高会减小，需要时请使用 `$(true)` 手动分行。调号 `1 = C` 和速度 `♩ = BPM` 分别具备独立的字号、字重设置，其中调整速度数字的显示字号不会改变实际播放速度。PDF 页边距选项通过 CSS `@page` 生效，浏览器打印窗口的手动页边距设置可能覆盖网页设置，建议保持打印对话框的默认页边距配置，不要手动选「无」或「自定义」覆盖网页设置。

### PDF 导出

点击「导出 PDF」，在浏览器打印对话框中选择 **另存为 PDF** 或 **Save as PDF** 即可。无需安装 PDF 库。 打印时会自动隐藏试听工具栏（播放、停止、速度、音色、缩放）以及源文编辑器和样式设置，只保留谱面。

### 支持范围

**连音记号：** 标准 ABC 中，圆滑线可写作 `(3 4 5)`，两个相同音高的延音线则使用 `-`；SanPu 已支持 `(3 4 5)` 的圆滑线解析与 SVG/PDF 弧线绘制，并在试听及 MP3 中为相邻音符增加很短的衔接；跨 `$(true)` 换行时弧线分段显示，但未实现同音延音线。SanPu 的 `3-` 已用于表示两拍音符，不能直接视作 ABC 延音线。歌词中的 `/` 只负责跳过一个音符位置，不绘制连音弧线。

第一版主要支持 **单声部简谱**、JPW-ABC 常见音符和 `.Words` 歌词结构。复杂反复记号、三连音、装饰音、多声部以及其它特殊控制指令可能不完整；遇到不识别的符号会提示，但不会自动覆写你的原始输入。试听使用严格按所记时值推算的合成音，不会尝试还原歌手的 Rubato 自由速度。

## GitHub Pages 自动部署

工作流：`.github/workflows/pages.yml`。推送到 `main` 或手动运行 `workflow_dispatch` 会先运行解析测试、生成包含 Git 提交号的版本清单，再通过官方 GitHub Pages Actions 发布静态网页。PR 只测试不部署。

若首次启用 GitHub Pages，请在 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。无须 PAT 或额外 Secrets。

## 一键打包 EXE 和 APK

工作流：`.github/workflows/native-apps.yml`。每次推送到 `main` 会自动构建，也可以在 GitHub 的 **Actions → SanPu — EXE and APK packages → Run workflow** 中手动一键触发。工作流会：

1. 运行全部单元测试并生成带提交版本的 Web 资源。
2. 在 Windows Runner 上生成 NSIS `*-setup.exe` 安装程序。
3. 在 Android Runner 上初始化 Tauri Android 工程并生成可安装 APK；APK 不在本地编译。
4. 上传单独的 EXE、APK，以及包含两者的 `SanPu-EXE-and-APK-*` 汇总构建产物。

当前 Windows 安装程序未配置商业代码签名，首次运行时 Windows 可能显示 SmartScreen 提醒。Android 工作流默认生成由 Runner 调试证书签名的可安装测试 APK；如需上架应用商店或让后续 APK 直接覆盖安装，应另外配置长期保管的 Android 发布签名密钥，密钥不得提交到仓库。

### 应用内检查更新

网页版、EXE 和 APK 共用同一套更新界面。应用启动后会读取安装包内的 `build-info.json`，并检查 GitHub Pages 上由 `main` 最新提交生成的版本清单：

- 顶栏始终可以手动点击「检查更新」。
- 发现新提交后，点击「立即同步最新版」会在当前应用窗口载入 GitHub Pages 最新构建，不必等待重新安装即可使用最新仓库功能。
- 当前谱稿、速度、音色和排版设置会通过 URL 片段迁移到最新版；片段不会发送给 GitHub 服务器。
- 无法联网时继续使用 EXE/APK 内置的完整版本。

## 谱面外观

默认预览采用白底黑字的传统简谱排版：居中大标题、左侧调号与相邻速度标记（例如 `1 = C   ♩ = 72`）、音符减时线/低音点、逐音对齐歌词，原始 `$(true)` 决定换行。即使 JPW-ABC 源文件包含 `3/4` 等拍号，谱面也不会显示拍号或错拍提示；不会绘制歌词延音的弧形连线。保留原始歌词、音符、时值和源文件拍号，不擅自修改。桌面端左侧编辑、右侧预览；窄屏默认等比缩放显示完整谱行，也可手动放大后横向滚动查看细节。PDF 打印会自动缩放到纸宽。
