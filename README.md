# 散谱 · SanPu

**旋律自由，不为凑拍子改谱。** 一个免费、开源、纯浏览器运行的散板数字简谱编辑器。无需注册、无需服务器、无需付费。

🌐 **在线体验：** https://shandianchengzi.github.io/SanPu/

## 功能

- **散板 / 自由节奏：** 允许不等长小节，不校验总拍数，不自动改动音符时值；谱面不显示源文件中的拍号。
- **数字简谱实时预览：** 支持 0–7、升降音、高低八度点、下划线减时、延长线、附点；调号旁标注当前试听速度（♩ = BPM）。不绘制歌词延音的弧形连接线。
- **歌词逐音对位：** `.Words` 中的 `/` 表示一个音符延续前面的歌词；空格和标点不占音符位置。标点独立绘制在文字侧边，不再导致对应音符下的歌词左移；可单独调整标点间距。
- **试听及自选音色：** 使用浏览器 Web Audio API 离线合成音符。右侧工具栏提供 7 种音色：纯音（原音色）、钢琴（合成）、吉他（合成）、长笛（合成）、弦乐（合成）、管风琴（合成）、电子方波。支持调速、暂停、停止，点击任一音符从该处播放；播放中切换音色会从当前位置接续，不会重置进度。
- **导出 PDF：** 使用浏览器系统打印功能选择「另存为 PDF」，SVG 矢量简谱，无水印。
- **导入 / 导出 JPW-ABC：** 支持 `.jpwabc`、`.txt`；兼容 UTF-8 和 UTF-16 字符编码；保存时保留编辑区中的原始音符、时值和歌词。
- **浏览器本地自动保存：** 不上传服务器，关闭网页可继续编辑（仅限同一设备浏览器）；另有「保存源码」手动备份。
- **完整排版面板：** 主工作区下方提供可收起的「谱面样式」面板，使用三个标签页整理 36 项设置。调号（`1 = C`）与速度标记（`♩ = 80`）支持独立字号和字重，其他项目涵盖标题、音符、歌词、线条、字体和 PDF 页面。
- **即时预览与排版预设：** 提供标准、紧凑、宽松三套预设，可逐项拖动滑块或输入精确数值，一键恢复默认。试听 BPM 直接在右侧预览工具栏调整。
- **自适应 SVG 预览：** 默认将完整谱行等比缩放至右侧预览栏宽度，窗口变化时自动适应；右侧预览工具栏可在 50%–300% 之间调整预览缩放，放大后支持横向滚动，一键恢复「适应宽度」。缩放仅影响屏幕预览，不改变 PDF 排版。
- **本地持久化：** 自定义外观、试听速度、音色和预览缩放一起保存在本机浏览器的 `localStorage`，重新打开网页自动恢复，不会修改原始 JPW-ABC 文本。
- **响应式布局：** 上方左侧只放源谱编辑、右侧放乐谱预览与播放/缩放工具；下方整行宽度的「谱面样式」默认折叠，展开后通过三个标签页选择不同选项。窄屏自动上下排布。

## 快速上手

打开网站，默认会载入一份《一生所爱》的个人听写示例。左侧编辑 JPW-ABC 源文，右侧立即预览、试听。歌词与旋律的匹配遵循歌词跳音规则，而不是根据小节拍数分配。

| 记法 | 含义 |
|---|---|
| `1`–`7`、`0` | 简谱音符和休止符 |
| `3_`、`3__` | 八分音符、十六分音符 |
| `3-`、`3--` | 两拍、三拍 |
| `3.`、`3_.` | 附点四分音符、附点八分音符 |
| `7,`、`1'` | 低音、高音 |
| `|` | 小节线，可自由分句（散板模式不校验小节长度） |
| `$(true)` | 分行 |
| `.Words` 中的 `/` | 一字多音：当前音符不另起新歌词 |
| `.Words` 中的 `{多字}` | 一组文字对应一个音符 |
| `W1@1,1:` | 第一段歌词从第一小节第一个音符开始 |

### 试听音色

右侧乐谱预览工具栏的「音色」下拉框可以直接切换播放音色，适合用不同的音质试听同一首简谱。音色使用 Web Audio 振荡器与谐波包络合成，不依赖外部音频文件、SoundFont 或在线服务；钢琴、吉他、长笛、弦乐、管风琴是**合成模拟音色**，不等同于真实乐器录音。默认保持先前版本的「纯音」，选择保存在浏览器本地。音色仅影响试听，不改变谱面、记谱时值及 PDF 导出结果。

### 排版调节

在「音符与歌词」标签页，支持分别调整**高音点与音符距离**、**低音点与音符距离**（各 -50～80 px，默认 0）。正值将音点移离音符，负值使音点靠近；调整会实时更新 SVG，较大偏移会自动增加谱行内部空间，避免高低音点被裁切。现有本地设置及预设保持原来的默认音点位置。

同一标签页新增**标点与歌词距离**（-30～80 px，默认 0）。歌词正文仍居中位于所属音符下，常见句读标点另外显示在文字右侧；成对的引号分别显示在文字两侧。这个设置只移动标点，不挪动歌词正文的水平锚点。渲染时优先读取浏览器实际字宽，避免字号或字体变化导致的居中偏移。原始歌词文本、对位和试听内容均保持不变。

在「间距与页面」标签页中，可以使用「相邻两行歌词间距微调」独立压缩或拉开谱面各行之间的距离，范围 **-160～160 px**，默认 **0 px**。此参数会在现有「谱行之间的间距」上叠加偏移：例如谱行间距为 17 px、歌词间距微调为 -40 px，两行间的实际附加空隙为 -23 px（相邻行将更靠近，极端值可能重叠）。注意 SVG 本身仍包含音符和歌词的高度，此数值不是两行歌词的绝对基线距离。

间距类参数现支持通过滑块或右侧数值框输入负数，包括曲名字符间距、曲名下方间距、调号与速度间距、调号下方间距、歌词字符间距、歌词相对音符的纵向位置、音符横向疏密以及谱行间距等；每个参数均有独立的负值下限。**字号、线条粗细、PDF 页边距等绝对尺寸不会允许负数**。设置即时预览并保存至浏览器本地，打印 PDF 时也按同一间距设置排版。极端负数可能造成叠字，请结合预览调整。

主工作区下方的「谱面样式」默认折叠，展开后可在「标题与调号」「音符与歌词」「间距与页面」三个标签页之间切换，支持方向键切换页签。每个数值都可以使用滑块粗调，或在右侧数值输入框中精确调整；修改立即更新右侧 SVG。字体使用浏览器与操作系统现有字体，不加载网络字体。大字号会自动扩展系统高度，避免音符附点、低音点、歌词相互遮挡。

「谱行最小宽度」控制 SVG 的逻辑宽度（viewBox），预览默认将整个谱行等比缩放至右侧容器宽度，不再需要默认横向滚动。可以使用右侧工具栏中的预览缩放滑块手动放大并横向滚动查看细节；导出 PDF 时始终适应纸张宽度，不采用屏幕缩放比例。PDF 版式保持设置的相对字号和间距；特别长的一行在缩放到 A4 纸宽时实际字高会减小，需要时请使用 `$(true)` 手动分行。调号 `1 = C` 和速度 `♩ = BPM` 分别具备独立的字号、字重设置，其中调整速度数字的显示字号不会改变实际播放速度。PDF 页边距选项通过 CSS `@page` 生效，浏览器打印窗口的手动页边距设置可能覆盖网页设置，建议保持打印对话框的默认页边距配置，不要手动选「无」或「自定义」覆盖网页设置。

### PDF 导出

点击「导出 PDF」，在浏览器打印对话框中选择 **另存为 PDF** 或 **Save as PDF** 即可。无需安装 PDF 库。 打印时会自动隐藏试听工具栏（播放、停止、速度、音色、缩放）以及源文编辑器和样式设置，只保留谱面。

### 支持范围

第一版主要支持 **单声部简谱**、JPW-ABC 常见音符和 `.Words` 歌词结构。复杂反复记号、三连音、装饰音、多声部以及其它特殊控制指令可能不完整；遇到不识别的符号会提示，但不会自动覆写你的原始输入。试听使用严格按所记时值推算的合成音，不会尝试还原歌手的 Rubato 自由速度。

## 本地运行

使用任意静态 HTTP 服务器（页面使用原生 JavaScript ES Modules）：

```bash
python -m http.server 8000
# 打开 http://localhost:8000
```

测试使用 Node.js 20+：

```bash
node --test tests/*.test.mjs
```

## GitHub Pages 自动部署

工作流：`.github/workflows/pages.yml`。推送到 `main` 或手动运行 `workflow_dispatch` 会先运行解析测试，再通过官方 GitHub Pages Actions 发布静态网页。PR 只测试不部署。

若首次启用 GitHub Pages，请在 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。无须 PAT 或额外 Secrets。

## 谱面外观

默认预览采用白底黑字的传统简谱排版：居中大标题、左侧调号与相邻速度标记（例如 `1 = C   ♩ = 72`）、音符减时线/低音点、逐音对齐歌词，原始 `$(true)` 决定换行。即使 JPW-ABC 源文件包含 `3/4` 等拍号，谱面也不会显示拍号或错拍提示；不会绘制歌词延音的弧形连线。保留原始歌词、音符、时值和源文件拍号，不擅自修改。桌面端左侧编辑、右侧预览；窄屏默认等比缩放显示完整谱行，也可手动放大后横向滚动查看细节。PDF 打印会自动缩放到纸宽。
